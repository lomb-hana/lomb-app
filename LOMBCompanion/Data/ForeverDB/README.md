# ForeverDB.net data snapshot

Data from ForeverDB.net (https://foreverdb.net), used with permission.
**Not covered by this project's MIT license.** The files in this folder belong to
ForeverDB.net's data terms; game data from the WoW Forever client is Blizzard's.

Anywhere LOMB Companion shows this data, it says "Data from ForeverDB.net" and shows
https://foreverdb.net. If you reuse this addon's code, don't copy this folder without
ForeverDB.net's permission.

If ForeverDB helps you, support them: https://buymeacoffee.com/foreverdb

The files are generated by `tools/build_foreverdb.py` from a cached pull of the
ForeverDB API (`tools/fdb_pull_all.py`, `tools/fdb_pull_extra.py`); the API key is
read from the `FOREVERDB_API_KEY` environment variable only and is never stored.
Do not edit them by hand. Each file's first lines give the snapshot date and the
WoW: Forever client build.

What's in it (levels 1-30): quests with givers, hand-ins and chains; vendors seen in
WoW Forever and what they sell; profession recipes up to skill 225; dungeons up to
the mid-30s with ForeverDB's notable-loot picks; and names of the items those mention.
Mob loot tables are not included -- the guild records its own.

Classic data: vendors and trainers never seen in WoW Forever are left out. Quests are
all in the Forever client and are kept; anything that comes from Classic (CMaNGOS)
data is flagged and shown as "(Classic data, may differ)".
