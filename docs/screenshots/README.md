# Screenshots

> **Previews only.** Every image here is a mock-up with sample data (the Quests & Items, guides and Ask LOMB shots are drawn from the bundled ForeverDB.net snapshot through the offline test harness). None are in-game captures: WoW: Forever launches November 4, 2026. Data from ForeverDB.net · https://foreverdb.net

Every shot shows the storybook look, which is the default since v0.6.15 (in-game 0.9.7). The Clean look is one choice away in Settings > Look; `theme/` has the two side by side.

The number at the start of each file name is the order the shots were made, so each folder reads in order.

| Folder | What's in it |
|---|---|
| [`core/`](core/) (10) | The main window: roster (and hiding alts), Me tab, settings (with the Look drop-down open), credits (including the ForeverDB.net credit), the minimap button, the welcome tour, the `/lomb test` report and the window dragged larger with tab and resize tooltips. |
| [`bestiary/`](bestiary/) (7) | Bestiary card, the full mob page, the Bestiary tab (with and without ForeverDB.net sections), rare filters, a search with no matches and the rare alert toast. |
| [`crafting/`](crafting/) (3) | Who can craft: the Crafters tab, search and whisper, and crafters on item tooltips. |
| [`news/`](news/) (5) | The guild activity feed, the Dungeons and Epic loot filters and the leaderboards (levels, weekly kills). |
| [`profiles-gear/`](profiles-gear/) (2) | Member profiles with gear and recent news, before and after inspecting. |
| [`events/`](events/) (3) | Guild events with attendance, past events and the attendance summary. |
| [`bank-wishlist/`](bank-wishlist/) (3) | Bank ledger, Wishlist and the bank/wishlist lines on item tooltips. |
| [`quests-items/`](quests-items/) (9) | Quests & Items: quest, item and recipe pages, quest chains and storylines, and the Loot browser (a dungeon, a whole dungeon, a boss and raids). |
| [`guides/`](guides/) (7) | Training, gathering, disenchanting, gear sets, zones, battlegrounds and rogue poisons. |
| [`ask-lomb/`](ask-lomb/) (4) | The Ask LOMB question box: quests, vendors and crafting, dungeons, typos, events and loot. |
| [`theme/`](theme/) (2) | The storybook look (the default since v0.6.15) and the Clean look side by side, and the storybook empty pages. |
